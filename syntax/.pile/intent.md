The Datalog language as text: what a program may say, and which programs are
refused because no host could evaluate them, whatever its relations held.

What belongs here decides what each clause is read as, where each mistake
is, and how a program is written back. It depends on nothing, so a tool that
only reads programs can take it alone. What a program derives does not
belong here, and neither does anything about where a relation's rows come
from: a host brings its own relations and its own meaning for `@reference`.
Its README is the specification of the language as written.

Read this pile to find out what a program may say and what parse refuses.
Change it when the language gains or loses something a program can write, or
when a mistake is reported differently.
